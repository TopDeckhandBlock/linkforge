# LinkForge

Добыча реферальных ссылок **Google AI Pro** через индийский selfcare **Jio**.
Арендует номер у SMS-провайдера, логинится в Jio по OTP, разбирает цепочку
активации предложения и забирает ссылку на redeem. Ссылки складываются в
SQLite, в текстовый файл и уходят в Telegram.

Одна ссылка = одно предложение = один Google-аккаунт. Номер одноразовый,
Jio-аккаунт живёт до первого redeem.

---

## Что нужно

| Что | Обязательно | Зачем |
|---|---|---|
| **Номера Jio** | да | без реального Jio-номера код не приходит вообще |
| Аккаунт PVACodes с балансом | да | номера берутся там, один ≈ **$0.20** |
| Python 3.10+ | да | запуск |
| Telegram-бот (токен + chat_id) | нет | доставка ссылок в ЛС; без него ссылки только в файле |
| Прокси | нет | разносит охоту по разным IP, когда Jio режет запросы с одного |

### Про номера — главное

- Нужен товар, который отдаёт **настоящие Jio-номера**, а не «похожие индийские».
  Рабочий вариант — `Jio50`. Прочие Jio-названия в каталоге либо отдают номера
  другого оператора, либо не принимают OTP от Jio (`INVALID_JIONUMBER`).
- До кода доходит **примерно каждый пятый** номер. Остальные — не Jio, уже
  активированы или не принимают OTP с этого IP. Это норма, а не баг.
- Пул у провайдера периодически **пустой**: каталог показывает остаток, а выдача
  отвечает `number list is empty`. Ферма в это время просто ждёт и не тратит деньги.
- Деньги за неудачный номер возвращаются автоматически: аренда отменяется через
  `OTP_FAIL_DELAY_SECONDS`, баланс пополняется обратно.

## Как это работает

```
аренда номера  →  Jio sendOtp  →  валидация OTP  →  логин (cookie)
      →  navigate(Z0241)  →  activate(Z0241)  →  google-ai
      →  redirectionURL (токен)  →  файл + Telegram
```

1. **Аренда.** PVACodes выдаёт номер и `activation_id`.
2. **OTP.** Jio отправляет код; код забирается у провайдера опросом.
3. **Логин.** Cookie-сессия Jio selfcare сохраняется в SQLite — её можно позже
   переиспользовать, чтобы перевыпустить токен без новой аренды.
4. **Активация.** Три запроса Jio OTT-сервиса открывают предложение Z0241 и
   отдают `redirectionURL` — это и есть ссылка на Google AI Pro.
5. **Доставка.** Ссылка пишется в `links/REDEEM.txt`, в базу и уходит в Telegram.

Если Jio вернул вёрстку вместо JSON, ссылка вытаскивается регэкспом по маркерам
(`serviceactivation.google.com`, `one.google.com/activate-plan`).

## Установка

```bash
git clone <этот репозиторий> linkforge
cd linkforge
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux / macOS
pip install -e .
```

## Настройка

```bash
cp .env.example .env
```

Минимум, что заполнить:

| Переменная | Значение |
|---|---|
| `PVACODES_EMAIL`, `PVACODES_PASSWORD` | вход в PVACodes |
| `PVACODES_SERVICE` | `Jio50` |
| `TG_BOT_TOKEN`, `TG_CHAT_ID` | свой бот от [@BotFather](https://t.me/BotFather); chat_id — свой numeric id |

Токен бота и ключи **не коммитить**: `.env` уже в `.gitignore`.

## Запуск

```bash
linkforge balance                 # сколько денег на провайдере
linkforge hunt                    # одна охота, ссылка в stdout
linkforge run --minutes 240       # ферма на 4 часа, ссылки в Telegram
linkforge run -m 60 -t 3          # остановиться на 3 новых ссылках
linkforge run -m 240 --no-telegram  # без бота, только файл
linkforge links -n 20             # что уже добыто
linkforge check -f links/REDEEM.txt  # проверить сохранённые ссылки
linkforge relink --phone 9xxxxxxxxx  # перевыпустить токен из старых cookie
```

Без установки пакета: `python -m linkforge <команда>` (при запуске из корня
репозитория пакет импортируется рядом лежащей папкой).

### Бот

Пока ферма работает, бот слушает только `TG_CHAT_ID` — чужие чаты игнорируются.

| Команда | Ответ |
|---|---|
| `/status` | баланс, попытки, найдено, аптайм |
| `/links` | последние 5 ссылок |
| `/balance` | баланс провайдера |
| `/help` | справка |

Каждая новая ссылка приходит отдельным сообщением сразу после добычи.

### Прокси

```dotenv
PROXY_ENABLED=1
PROXY_SOURCE=file
PROXY_FILE=C:/path/to/proxies.txt    # по одному на строку
PROXY_POOL_SIZE=20
PROXY_TEST_URL=https://www.jio.com/api/jio-authenticate-service/authenticate/authJsonData
```

- Пул держит `PROXY_POOL_SIZE` живых выходов и обновляется каждые
  `PROXY_ROTATE_SECONDS`.
- Каждый прокси проверяется реальным запросом к `PROXY_TEST_URL`; мёртвые
  отбрасываются до начала охоты. Чистый IP получает `200`, забаненный — `403`,
  поэтому проверка отсекает именно бан.
- Одна охота = один прокси на всю цепочку (OTP → логин → активация). Cookie
  старых сессий по умолчанию идут напрямую: сессия заработана на другом IP,
  и Jio может счесть прыжок угоном (`PROXY_SESSIONS=1` включает и это).
- Фри-списки живут недолго: в замере из 50 случайных рабочих оказалось 5.

## Сколько это даёт

- **Один номер → одна ссылка.** Перевыпуск токена (burst relink) даёт N строк
  для того же единственного предложения: после redeem или рецикла номера они
  умирают одновременно. Поэтому ферма отдаёт ровно одну ссылку за охоту.
- Ссылка одноразовая и живёт **~30–60 минут**; активировать нужно на нужном
  Google-аккаунте.
- Успех зависит от выдачи номеров, а не от скорости кода: при пустом пуле или
  отсутствии Jio-номеров попытки дешёвые и ничего не стоят.

## Проблемы и ответы

**`number list is empty`, `All channels are busy`** — пул провайдера пуст,
ферма ждёт. Лечится только временем или другим товаром/провайдером.

**`NOT_JIO` / `INVALID_JIONUMBER`** — выданный номер не Jio. Аренда отменяется,
деньги возвращаются; попробуйте другой товар из очереди (`PVACODES_SERVICE=Jio50,Jio14`).

**Код не приходит** — OTP Jio уходит не на каждый номер; часть номеров уже
активирована. Авто-возврат сработает через `OTP_FAIL_DELAY_SECONDS`.

**Ссылка не активируется** — истекла (30–60 минут) или уже использована.
`linkforge check` покажет `DEAD` только при явном отказе токена; страница входа
Google — нормальный ответ и для живой, и для потраченной ссылки.

**Всё падает на 403 / `Access Forbidden`** — IP забанен Jio. Проверка:
`linkforge hunt` покажет ошибку; помогает другой выход (прокси/сеть).

**Низкий баланс** — ферма паркуется на 30 секунд и ждёт возвратов, а не долбит
провайдера с нулём.
