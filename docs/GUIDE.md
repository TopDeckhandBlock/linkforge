# Полный гайд: от нуля до ссылок в Telegram

Пошагово, без предположений. Каждый шаг заканчивается проверяемым результатом.

---

## 0. Что ты получишь в конце

Приложение, которое само:
1. арендует индийский Jio-номер за ~$0.20;
2. логинится в Jio selfcare по SMS-коду;
3. активирует предложение Google AI Pro и вытаскивает реферальную ссылку;
4. присылает её в твой Telegram и складывает в файл.

Время от нуля до первой ссылки — ~30 минут, из которых 25 — регистрация и
пополнение. Ссылки появляются тогда, когда у провайдера есть настоящие
Jio-номера: пул периодически пустой, это нормально.

---

## 1. Аккаунт и деньги у SMS-провайдера

1. Открой **https://beta.pvacodes.com**, зарегистрируйся (почта + пароль).
2. Пополни баланс минимум на **$2–5** (один номер ≈ $0.20, до живой ссылки
   доходит примерно каждый пятый номер — остальное возвращается авто-отменой).
3. Проверь, что видишь каталог товаров: там должны быть строки вида `Jio50`,
   `Jio11` и т.п.

**Проверка:** ты на сайте, баланс виден, каталог открывается.

## 2. Telegram-бот для доставки и панели

1. Открой **@BotFather** → `/newbot` → имя и username.
2. Скопируй токен вида `123456789:AA...`.
3. Узнай свой numeric chat_id: напиши боту **@userinfobot** любое сообщение,
   он ответит `Id: 123456789`.

**Проверка:** токен сохранён, chat_id записан.

## 3. Установка софта

```bash
git clone <репозиторий> linkforge
cd linkforge
python -m venv .venv
.venv\Scripts\activate          # Windows; на Linux: source .venv/bin/activate
pip install -e .
```

Нужен Python 3.10+ (`python --version`).

**Проверка:** `linkforge --help` печатает список команд.

## 4. Настройка

```bash
cp .env.example .env
```

Открой `.env` и заполни:

| Переменная | Откуда |
|---|---|
| `PVACODES_EMAIL` / `PVACODES_PASSWORD` | шаг 1 |
| `PVACODES_SERVICE` | `Jio50` — не меняй, пока не прочитал «про номера» в README |
| `TG_BOT_TOKEN` | шаг 2 |
| `TG_CHAT_ID` | шаг 2 |

**Проверка:** `linkforge balance` печатает сумму в долларах.

## 5. Первый запуск

Одна охота, чтобы увидеть всю цепочку в терминале:

```bash
linkforge hunt
```

Возможные исходы и что они значат:

| Вывод | Значение | Деньги |
|---|---|---|
| ссылка `https://...` | готово, активируй в течение ~30–60 минут | потрачены $0.20 |
| `no link this time` + «не абонент Jio» | провайдер отдал не-Jio номер | вернутся сами |
| `number list is empty` | у провайдера сейчас пусто, дождись пополнения | не тратятся |

## 6. Ферма с панелью в боте

```bash
linkforge bot -m 240      # панель + ферма на 4 часа
```

В Telegram придёт карточка с кнопками: **Запуск 60/240 мин · Стоп · Статус ·
Баланс · Ссылки · Одна охота · Настройки · Логи**. Каждая свежая ссылка —
отдельным сообщением. В `Настройках` можно включить/выключить прокси не
перезапуская процесс.

## 7. Куда смотреть потом

- ссылки: `links/REDEEM.txt` и `linkforge links`;
- история охот: `results.db` (таблица `hunts`), сессии логинов — `sessions`;
- проверка старых ссылок: `linkforge check -n 20`;
- перевыпуск ссылки из старого логина: `linkforge relink --phone <номер>`.

## 8. Сколько это стоит

При пустом пуле и неудачных номерах — почти ничего: каждая аренда либо
доходит до ссылки ($0.20), либо отменяется с возвратом. Реальная цена
живой ссылки на практике ≈ $0.8–1.5 с учётом доли неудач.

---

## Частые ошибки

- **`PVACODES_EMAIL ... не заданы`** — `.env` не скопирован/не заполнен.
- **`balance` падает с ошибкой сети** — проверь логин-пароль на сайте
  провайдера; пароль с нестандартными символами лучше заключить в кавычки.
- **Бот молчит** — токен/`TG_CHAT_ID` неверные, или ты не нажал Start у бота
  в Telegram.
- **Панель не отвечает на кнопки** — кто-то ещё поллит этого бота: `linkforge
  bot` должен быть запущен ровно в одном месте.
